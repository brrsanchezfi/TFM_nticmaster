# Versión de DKOps usada por los cuatro casos de uso del TFM.
# Se fija un tag concreto, nunca "main", para que el proyecto sea reproducible.
#
# Instalación:
#   pip install "dkops[local] @ git+https://github.com/brrsanchezfi/DKOps.git@v0.3.0"
#
# El extra [local] añade pyspark 3.5.3 y delta-spark 3.2.0 para desarrollo y
# tests offline. En Databricks NO se instala ese extra: pyspark lo aporta el
# runtime del cluster, y la única dependencia real de DKOps es loguru.
#
# Nota de reproducibilidad: el wheel construido desde el tag v0.3.0 se
# identifica internamente como 0.2.4 — la versión del pyproject.toml de DKOps
# no se subió al taguear. El tag de git es la referencia fiable.

v0.3.0
