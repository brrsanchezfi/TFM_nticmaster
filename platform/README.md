# Platform

`dkops_version.txt` fija la versión de DKOps que usan los cuatro casos de uso,
con el histórico de versiones y lo que corrigió cada una.

La dependencia se declara por tag, nunca por rama:

    dkops[local] @ git+https://github.com/brrsanchezfi/DKOps.git@v0.3.5

Este directorio no contiene código.
